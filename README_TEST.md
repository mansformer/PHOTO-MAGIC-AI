# PHOTO MAGIC AI v0.8 — бесплатный ИИ на устройстве

## Бесплатно, без API-ключа и платы за запросы
MediaPipe Selfie Segmentation v0.1.1675465747 (Apache-2.0) включён в APK вместе с файлами WASM и TensorFlow Lite.

**Функции:** выделение человека и удаление заднего плана в прозрачный PNG, размытие фоновой области, белый/тёмный фон или фиолетовый градиент. Пиксели исходного человека не генерируются заново: меняется только маска прозрачности и фон.

**Как запустить:** загрузить своё фото → раздел «ИИ» на нижнем горизонтальном меню → карточка «Убрать фон · БЕСПЛАТНО» → «Обработать бесплатно» → выбрать фон → «Сохранить PNG» или «Применить». Полученный PNG сохраняется в Pictures/PhotoMagicAI на Android.

**Ограничения:** модель ориентирована на людей и портреты. Машины и отдельные предметы могут быть выделены плохо. Края волос требуют проверки. Тест на реальном Android всё ещё необходим. Аппаратная WebGL/WASM совместимость зависит от устройства.

**Безопасность:** фото не отправляется на Railway или внешний API в бесплатном режиме. В составе APK упакованы библиотека, модель и WASM. В отдельной браузерной HTML-версии при отсутствии локальных файлов модели возможна загрузка с CDN; в APK внешний интернет для модели не нужен. Бесплатная обработка не расходует кредиты.

**Облачный ИИ:** старый тестовый интерфейс доступен отдельно, однако не работает без ключа и отдельного разрешения. На Railway платный AI_ENABLED оставлен выключенным.
