# PHOTO MAGIC AI v0.4 — test Android app

**Что работает офлайн:**
- Галерея фотографий: нажатие на демо-фото или кнопку «Фото» открывает системный выбор изображения.
- Горизонтальный нижний редактор без вертикального листания разделов: Эффекты, Магия, Свет, Кадр, Текст, Стикеры, Рамки, ИИ и Экспорт.
- Выразительные цветовые фильтры и 30 новых магических эффектов с частицами, свечением, неоном, северным сиянием, призмами и атмосферными наложениями. Старые рецепты сохранены, но число не выведено в интерфейс.
- Контроль интенсивности, кадрирование, надписи и экспорт JPG/PNG.
- Экспорт до 4096 пикселей по длинной стороне, **без ИИ-апскейлинга**. Если оригинал меньше, детали не дорисовываются.
- На Android 10+ готовое изображение записывается в галерею `Pictures/PhotoMagicAI` с помощью MediaStore. В браузере сохранение работает как скачивание файла.

**Что пока не работает:** 30 облачных ИИ-инструментов, подписки, серверная обработка. Все они отображаются как будущие функции, без имитации их результата.

## Как скачать APK
Открой GitHub Actions → последний успешный run «Build PHOTO MAGIC AI test APK» → Artifacts → `PHOTO-MAGIC-AI-test-debug-APK`. Распакуй `app-debug.apk` и установи на Android.

Сборка автоматически запускается при изменении ветки main, а также может запускаться вручную (Run workflow). APK предназначен для тестирования, не для публикации в магазине.
