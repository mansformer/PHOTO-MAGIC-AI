# PHOTO MAGIC AI v0.3 — Android test APK

Это тестовая офлайн-версия: 480 локальных фотоэффектов (16 коллекций по 30), редактирование/экспорт JPG/PNG, каталог 30 будущих AI-инструментов. **Облачный AI, оплаты и подписки ещё не работают.**

## Получить APK
1. Открой GitHub → **Actions** → **Build PHOTO MAGIC AI test APK**.
2. Workflow запускается автоматически при изменениях ветки main, а также вручную кнопкой **Run workflow**.
3. После успешного выполнения выбери последний run и внизу в **Artifacts** скачай `PHOTO-MAGIC-AI-test-debug-APK`.
4. Распакуй ZIP и установи `app-debug.apk` на Android. Это debug-подпись для тестирования, не релизная сборка.

## Как собирается
GitHub Actions на Ubuntu выполняет npm install, создает Android-проект Capacitor, запускает gradle assembleDebug и публикует APK в artifact.

## Ограничения
Работа с фото выполняется на устройстве. Эффекты работают офлайн после установки. Карточки AI пока только интерфейс и не делают облачную генерацию. Для будущего релиза потребуются тесты на реальных Android-устройствах и оформление разрешений/политики конфиденциальности.
