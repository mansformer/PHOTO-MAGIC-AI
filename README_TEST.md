# PHOTO MAGIC AI v0.5 — тестовый Android APK

**Изменения интерфейса:**
- Фото занимает почти весь экран, под ним только одна горизонтальная лента эффектов с прокруткой влево и вправо.
- Всего 430 локальных эффектов: 400 цветовых рецептов (16 коллекций × 25) и 30 магических наложений.
- Сначала показаны заметно разные стили. Через кнопку «Коллекции» доступны все группы.
- Остальные функции не располагаются друг над другом: они открываются через меню «Инструменты», разделённое на «Фотография», «Декор» и «Дополнительно».
- Нажатием на фото открывается системная галерея.
- Экспорт JPG/PNG, выбор размеров до 4K без генеративного увеличения деталей.
- Для Android используется отдельный модуль сохранения в Pictures/PhotoMagicAI.
- Отступы учитывают строку состояния Android; название приложения не должно перекрываться системными значками.

**ИИ:** 30 будущих облачных ИИ-инструментов представлены интерфейсом, облачная обработка пока не подключена.

**Автоматическая сборка:**
1. GitHub → Actions → Build PHOTO MAGIC AI test APK → последний успешный запуск.
2. В разделе Artifacts скачать PHOTO-MAGIC-AI-test-debug-APK.
3. Распаковать ZIP и установить app-debug.apk.

Это тестовый APK; реальное поведение на разных физических устройствах необходимо проверить.
