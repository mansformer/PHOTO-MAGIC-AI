# PHOTO MAGIC AI v0.7 — тестовый Android APK

## Переработанный фоторедактор
- Большая фотография наверху, красивая тёмная фотостудия с фиолетовым свечением.
- В самом низу: **одна горизонтально прокручиваемая панель разделов**: Эффекты, Магия, Свет, Кадр, Текст, Стикеры, Рамки, ИИ и Экспорт. Переключение по нажатию без отдельного окна.
- Внутри «Эффекты» — собственная горизонтальная карусель категорий: Лучшие, Все, Магия, Кино, Плёнка, Ч/Б, Портрет, Ретро, Неон и другие (16 тематических коллекций).
- Следующим рядом **горизонтально** листаются миниатюры эффектов из выбранной категории, а не дублирующие вертикальные меню.
- **430** доступных офлайн-эффектов: 400 цветовых рецептов + 30 магических. В «Все» постепенно подгружаются следующие карточки при горизонтальной прокрутке для скорости.
- Управление силой эффекта; отмена/повтор, загрузка своего фото касанием, экспорт JPG и PNG до 4K (без ИИ-дорисовки).
- Остальные функции открываются по разделам снизу, а не накладываются друг на друга.

## ИИ
- Подготовлена защищённая интеграция с тестовым сервером для 14 основных ИИ-операций, но сервер и API-ключ **не включены**.
- Остальные 16 ИИ-функций по-прежнему требуют отдельной реализации. Офлайн-редактор работает без сети.
- При генеративном редактировании сохранение идентичности лица невозможно гарантировать на 100%; требуется сравнение с оригиналом.

## Установка
GitHub → Actions → Build PHOTO MAGIC AI test APK → последний успешный запуск → Artifacts → PHOTO-MAGIC-AI-test-debug-APK → распаковать ZIP и установить app-debug.apk. 
Debug APK для теста, не для публикации в магазине.
