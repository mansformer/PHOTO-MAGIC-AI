PHOTO MAGIC AI v0.6 — тестовый серверный API

Сервер не тратит деньги, пока AI_ENABLED=false либо не задан OPENAI_API_KEY.

Развёртывание в Railway:
- Root Directory: api
- Start Command: node server.mjs
- Runtime: Node.js 22+
- Variables (через защищённую панель Railway): OPENAI_API_KEY, APP_TEST_TOKEN, ALLOWED_ORIGINS=https://localhost, AI_ENABLED=true.
- После настройки проверка: GET https://YOUR-DOMAIN/health.

Для проверки Android ввести URL своего сервера и тестовый пароль в разделе «ИИ». Пароль хранится только в памяти на время запуска приложения; ключ OpenAI НИКОГДА не хранится в APK.

Реальные тестовые операции через один генеративный image-edit endpoint: enhance, old-photo, colorize, remove-bg, replace-bg, studio-light, product-cut, product-scene, headshot, poster, sky, recolor, hair, retouch.
Остальные специализированные модули остаются недоступными, пока не реализованы точные маски и другие модели.

Важное:
- Генеративное редактирование НЕ гарантирует идеального сохранения лица. Сравнивать результат с оригиналом обязательно.
- Не сохраняем пользовательские фото и готовые изображения на сервере, но фото уходит к поставщику ИИ; его правила хранения надо учитывать.
- APP_TEST_TOKEN — только ограниченная тестовая защита. Перед публичным запуском нужны настоящие аккаунты, серверное списание кредитов, защита от злоупотреблений и бюджетные лимиты.
- Каждая успешная обработка может создавать расходы в API. Сначала задайте месячный бюджет в кабинете провайдера.
